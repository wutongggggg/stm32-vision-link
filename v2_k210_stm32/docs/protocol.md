# I2C 通信协议与寄存器

## 基本参数

| 项 | 值 |
|---|---|
| 器件地址（7 位） | `0x32` |
| 速率 | 100 kbps（可到 400 kbps） |
| 寄存器地址 | 16 位，线性地址空间 0x0000 ~ 0xFFFF |
| 寄存器地址字节序 | **低字节先**（实测；version 寄存器可校验） |
| 坐标数据 | 16 位，低字节在前（小端） |
| 显示分辨率 | 320 × 240 |

## 一次寄存器读取的时序

```
START → [0x32<<1 | W] → 寄存器低字节 → 寄存器高字节
      → 重复START → [0x32<<1 | R] → 读 N 字节(末字节 NACK) → STOP
```
连续读时器件寄存器地址自增，因此可一次性读出 `x/y/w/h` 连续 8 字节。

## 校验：固件版本寄存器

| 寄存器 | 地址 | 说明 |
|---|---|---|
| SYS_FIRMWARE_VERSION | 0x0000 | 连续 16 字节为版本字符串（本机读出 `v0.7.4`） |

## 颜色识别相关寄存器

| 寄存器 | 地址 | R/W | 说明 |
|---|---|---|---|
| COLORDETECT_BASE / _CURRENT_FUNC | 0x1000 | R | 结果刷新寄存器；读取值 = 当前运行的功能号 |
| COLORDETECT_RESULT_NUM | 0x1001 | R | 当前识别到的颜色块数量（0 表示无） |
| COLORDETECT_RESULT_IDS | 0x1002 | R | 第一个识别颜色的 ID |
| COLORDETECT_RESULT_XL / XH | 0x1030 / 0x1031 | R | 第一个目标 x 坐标（低 / 高字节） |
| COLORDETECT_RESULT_YL / YH | 0x1032 / 0x1033 | R | 第一个目标 y 坐标 |
| COLORDETECT_RESULT_WL / WH | 0x1034 / 0x1035 | R | 第一个目标宽度 |
| COLORDETECT_RESULT_HL / HH | 0x1036 / 0x1037 | R | 第一个目标高度 |

- 目标中心：`CX = x + w/2`，`CY = y + h/2`；画面水平中线为 160。
- 多个目标时，后续目标结果按每 16 字节偏移（0x1040 起为第二个目标）。

## 坐标系

左上角为原点 O，X 向右为正（0~319），Y 向下为正（0~239）。

## 功能号（SYS_CURRENT_FUNC / 0x0035、0x1000 读取值）

面部识别 1、物体识别 2、图像分类 3、特征学习 4、颜色识别 5、循线 6、标签 7、二维码 8、条形码 9、无 0。
